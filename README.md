# Banaras Dev Deepawali — React/Vite

Premium, mobile-first, single-page React website for Dev Deepawali boat enquiries in Varanasi.

## Stack
- React 19
- Vite 7
- Plain CSS
- Static deployment on Vercel or Netlify

## Run
`npm install`
`npm run dev`

## Build
`npm run build`

## Performance
Hero image is preloaded; below-the-fold images use native lazy loading, async decoding and responsive sizes. No external font or UI library is loaded. For maximum Lighthouse performance, replace remote Wikimedia URLs with locally hosted AVIF/WebP derivatives before final production.

## SEO
Includes optimized title/description, Open Graph, Twitter cards, robots, JSON-LD and semantic headings. Add the final canonical URL and sitemap after purchasing the domain.
